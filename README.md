# Avaliacao_Aquila
Desenvolvimento de um ETL envolvendo a API NYC TLC Trip Record Data para a avaliação de uma oportunidade de engenheiro de dados pleno

## Variáveis de ambiente
Para não expor segredos no repositório, configure as credenciais localmente em um arquivo .env (não versionado).

Copie o exemplo e ajuste os valores antes de subir os containers:

```bash
cp .env.example .env
```
